# Simulation

`tools/` contains arena generation, floor-plan rendering and guarded Linux
launch synchronization. Robot models, SDF worlds, targets and launch files
remain in `../src/edgeai_robot_description/` as ROS package resources.

Run simulation through the root `Start-Simulation.ps1`; shell runtime support
is in `../scripts/simulation/`. Validation code is in `../tests/simulation/`.
