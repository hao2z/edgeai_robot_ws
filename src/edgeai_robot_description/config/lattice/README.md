# Differential-drive lattice primitives

`diff_5cm.json` is an unmodified Nav2 sample control set (Apache-2.0), from
`ros-navigation/navigation2` revision `d5d768b7b38a05e7cfd2b6c693b786b402161bed`,
path `nav2_smac_planner/lattice_primitives/sample_primitives/5cm_resolution/0.5m_turning_radius/diff/output.json`.
It includes differential-drive motion primitives, with 0.05 m grid resolution
and 16 headings, and remains available as a historical comparison.

`diff_5cm_r020.json` is the current control set, generated by the unchanged
upstream generator at the same revision with `motion_model=diff`,
`turning_radius=0.20`, `grid_resolution=0.05`, 16 headings and stopping threshold 5.
It retains in-place turns. Regenerate with `bash scripts/setup/generate-lattice.sh`;
the input JSON and isolated generator environment/lockfile are versioned under
`algorithms/exploration/`. Source and generated visualizations stay in local caches/results.

The navigation YAML uses a config-relative lattice path; the exploration runner
resolves it to an absolute path in the per-run YAML. Preserve matching costmap
resolution. Smaller curve radius requires lower speed; it does not reduce the
physical collision footprint or guarantee successful narrow-space navigation.
