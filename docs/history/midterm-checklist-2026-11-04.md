## 验收范围

两部分独立演示。第一部分自主探索、实时 SLAM 和相机识别；第二部分可加载提前准备的地图，直接使用给定目标坐标完成单机与双机救援，无需沿用第一部分地图或重新识别。中期不强制 LLM、地图融合或完整 explore–detect–plan–rescue 集成。

| 项目 | 文档要求 | 验收证据 |
| --- | --- | --- |
| 总时间 | 任务合计 13 分钟，另有 2 分钟结果核验；启动软件不计时，任务切换计时 | 探索开始、切换、两项救援完成、总耗时记录 |
| 第一部分 | 建议约 6 分钟，无单独硬时限；至少一台机器人从起始区自主探索并建图 | RViz2 地图、保存的占据栅格地图 |
| 第一部分初始状态 | 不得加载旧占据地图，也不得保留先前累计建图、探索状态或检测结果 | 清空与启动记录、本轮独立输出目录 |
| 自主性 | 自动生成探索目标可以；实时人工选下一个探索目标、遥控、预录运动回放不允许 | 自动派发目标和运行日志 |
| 视觉识别 | 相机识别 S1 和 C1；记录 ID、类型、视觉估计的相对位置及检测时间 | 检测叠加图、ROS 2 话题或日志；相对位置在相机或机器人坐标系表达 |
| S1 救援 | 至少一台机器人，其 base_footprint 到 S1 中心的水平距离在 0.5 m 内，连续 10 秒 | 距离历史、连续停留计时、完成状态 |
| C1 救援 | 两台机器人各自到 C1 中心的水平距离在 0.7 m 内，同时连续 10 秒 | 两机距离、共同条件与共同计时、完成状态 |
| 停留计时 | 使用仿真时间；任一必需机器人出界，相应连续计时重置 | 越界重置记录及仿真时间戳 |
| 第二部分起点 | 两台机器人均在左下起始区，靠近图示位置；精确坐标和朝向不限，初始无碰撞 | 初始位姿与 Gazebo 截图 |
| 任务分配 | 按目标类型自主分配一台或两台机器人，自主执行状态转换 | 任务分配、导航结果及状态日志 |
| 碰撞 | 避免机器人之间及与墙、障碍、标记支架的碰撞 | 碰撞状态记录；不能仅凭代价地图警告判定实体碰撞 |

10 秒是仿真时间。文档未明确说明合计 13 分钟采用墙钟还是仿真时钟，应向组织方确认；实现和排练同时记录两种时间，暂按 13 分钟墙钟预算准备。文档未规定专用评分界面、报告模板或上传文件格式，不能将内部建议的文件名当成官方提交格式。

## 场地和标记基准

| 对象 | 要求 |
| --- | --- |
| 边界 | 5.0 m × 5.0 m；墙厚约 0.1 m |
| 起始区 | x ∈ [0, 1.4]，y ∈ [0, 1.0] |
| S1 | 中心 (1.0, 4.1)，ID 1，单机半径 0.5 m |
| C1 | 中心 (4.1, 1.0)，ID 2，双机半径 0.7 m |
| W1 | (0, 3.1) 至 (2.2, 3.1) |
| W1b | (2.2, 3.1) 至 (2.2, 3.6) |
| W2 | (3.4, 0) 至 (3.4, 2.8)，与下边界连接 |
| O2 | 中心 (2.2, 2.0)，矩形 0.6 m × 1.0 m |
| O3 | 中心 (4.4, 3.6)，矩形 0.8 m × 0.6 m |
| 字典 | OpenCV DICT_4X4_50 |
| 标记安装 | 静止、独立支架、竖直平面、白边；推荐黑色标记边长 0.16 m，不含白边；中心离地约 0.35 m |
| 朝向 | S1 朝下方开阔区域；C1 朝北侧开阔接近方向 |
| 距离参考 | 目标中心是支架正下方地面点；机器人参考为 base_footprint |

场景由团队自行搭建，第二部分地图也由团队提前准备，组织方不提供现成 world 或地图。可按相机视场调整支架设计，但需保留名义标记参数、中心位置和安全接近条件；主要几何或目标坐标变更需事先与组织方约定。Figure 1 用于布局核对，数值以正文第 3 节和图中参数表为准，不从示意图像素反推坐标。
