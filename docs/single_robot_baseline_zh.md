# 单机器人仿真基线

本流程覆盖启动、传感器、TF、低速移动、转向、停止、SLAM、地图导出和重新加载。它是练习场地中的基础验收，自主探索、ArUco 检测、Nav2 导航和救援任务属于后续工作。

## 运行

在仓库根目录执行，首次使用前需完成 Pixi 安装和 ROS 工作区构建：

```bash
pixi install --locked
pixi run colcon build --symlink-install
./scripts/run_single_robot_baseline.sh --gui
```

本机 Pixi 在外层 `tools/bin/`，脚本能自动找到；手动构建可使用 `../tools/bin/pixi run colcon build --symlink-install`。

不打开 Gazebo/RViz 窗口时：

```bash
./scripts/run_single_robot_baseline.sh
```

不打开窗口仍需支持 Ogre2 的图形驱动，GPU LiDAR 和相机依赖渲染。脚本会自行启动全新的仿真及 SLAM，不必提前运行 `start_sim.sh`。验收结束后自动关闭自己启动的进程，按 Ctrl+C 可以中断。

脚本采用 ROS Domain 71、仅本机发现和独立的 Gazebo partition。测试用 `/cmd_vel` 在该域发布，仅用于新启动的仿真。不要同时运行两个验收，也不要把实际机器人接入同一域。

## 检查内容及通过条件

- 接收到推进的仿真时钟、里程计、关节、360 点 LiDAR、640×480 RGB/深度图、相机内参和点云；深度含有效值。
- `odom → base_footprint → lidar_link/camera_link` 和点云兼容坐标变换存在；SLAM 后 `map → base_footprint` 可查询。
- 出生位置接近官方配置的 `(-1.5, -1.5, 0)`，没有其他控制发布器。
- 在前向 LiDAR 保持至少 0.55 m 空间时，以 0.1 m/s 前进 2 秒仿真时间；真实位移在 0.12–0.30 m，方向向前，侧向偏差小于 0.04 m，与里程计距离差小于 0.05 m。
- 以 0.2 rad/s 逆时针转向 2 秒仿真时间；真实转角在 0.25–0.60 rad，与里程计转角差小于 0.10 rad，平移小于 0.05 m。
- 两段运动后均明确发送零速度。最后停止后观察 1.5 秒仿真时间，位移小于 0.01 m，转角小于 0.03 rad。
- 运动过程中检查传感器和真值是否超时，并限制机器人留在出生点半径 0.65 m 范围内；异常时发送零速度并关闭本次仿真。
- SLAM 生成分辨率 0.05 m、包含有效空闲和占据单元的地图。
- Nav2 Map Saver 导出地图，验证 YAML 和 PGM 尺寸；另启 Map Server，配置并激活后在独立话题重新加载地图。检查尺寸、分辨率、占据单元和原点；允许 YAML 保存原点时带来的小于 1 mm 舍入差。

这些阈值是本项目的基础回归条件，不是比赛官方判分标准。运动真实位姿通过 Gazebo `/world/empty/dynamic_pose/info` 独立读取，仅作为验收参考，不提供给 SLAM 或导航。Gazebo 世界坐标和 odom 的初始原点不同，轨迹图绘制时进行了初始位姿对齐。

## 输出

每次结果保存在新的 `artifacts/baseline_日期_时间/` 目录，可通过 `--output /absolute/new/directory` 指定。为避免覆盖记录，指定目录必须尚不存在。

- `REPORT.md`、`report.json`：检查结果、数值、Git 版本及依赖锁文件哈希。
- `trajectory.csv`、`trajectory.png`：真实位姿和里程计轨迹、航向变化。
- `camera.png`：实际相机图像。
- `map.yaml`、`map.pgm`、`map.png`：地图及预览。
- 各进程的 `.log`：用于故障定位；GUI 模式另保存本次 RViz 配置。

所有检查通过时退出码为 0，失败或中断为 1。输出目录已加入 `.gitignore`；需要共享实验结果时应单独选择报告，不要把整个环境和构建产物提交。

## 已知限制

短距离低速直行与停止可以通过，不表示碰撞情况下的里程计正确。官方基线仍存在碰撞时轮式里程计漂移的问题；本流程不主动制造碰撞。

原地转向也可能伴随几厘米平移，实际轨迹会记录这种偏移。这说明轮式里程计不等同于真值，后续定位应融合环境观测。本验收没有证明长时间运行、全场地图覆盖、所有相机/点云坐标方向或实机控制正确。

## 本机验证记录（2026-10-29）

图形模式和仅服务器模式均通过全部检查。最终图形模式实测前进 0.2099 m、转向 0.4012 rad（约 23.0°），转向伴随平移 0.0354 m，最终停止观察期间位移和转角均未继续变化。地图为 101×101、0.05 m/格，导出后能由独立 Map Server 重新发布。另在运动开始时发送终止信号，验证了停止、进程清理和失败报告生成流程。
