# 救援停稳窗口与车身边距

本次依据会话`20261111-160323-911-domain86`，不另行启动仿真。

S1在136.34仿真秒宣布达标。真值最后10秒内最大距离0.359m、最大朝向误差2.7°，均合格；采样估算角速度0.0565rad/s超过停车阈值0.05。将核验终点移到136.84秒，同一份历史数据即可通过，最大角速度为0。不是缺少真值数据，也不应放宽核验阈值。

S1和C1配置新增`settle_margin_s: 1.0`。任务连续满足条件11秒后才结束；期间任何失效仍重置计时，真值照常检查最后10秒。这样保留1秒稳定余量，不改变比赛要求。读取真值仍有最多3墙钟秒的采样补齐等待；这与持续停车的仿真时间是两回事。

C1后期两车均报205（起点占据）。将首次报错的起始位姿投影到保存的`cooperative-map`，padding为0、0.005、0.01、0.02、0.04m时，完整车身都通过静态地图空闲检查。静态地图和其padding不足以解释这次占据。原始激光动态障碍、对方标记及其离散栅格仍需区分；本轮没有保存动态代价地图，不能确定是哪一层造成。

此前局部padding为0.005m、全局被Lattice代码从0.01强制增大到0.02m，对方另加0.02m；C1静态筛选默认0.005m、双车分离默认每车0.04m，规则不一致。

现在统一调节入口是`src/edgeai_navigation/config/nav2_exploration_rectangle.yaml`局部地图的`footprint_padding: &body_padding 0.01`。全局用YAML别名引用；删除Lattice强制增大值，对方标记、S1及C1筛选从实际运行配置派生。旧比较profile仍可明确覆盖自己的几何配置。

对方障碍通过两条路径加入：原始激光进入ObstacleLayer，显式对方位姿进入PeerFootprintLayer。两层占据取并集，不是将相同位置的代价值相加；InflationLayer只执行一次。雷达保留实际返回，可覆盖相对定位偏差造成的显式车身标记误差；定位专用过滤扫描不作为避障输入。显式车身是254硬障碍，膨胀外圈是代价梯度；减小cost_penalty不能消除254占据。当前RPP未开启基于代价的速度缩放，因此不能将其停车简单归因于软代价减速。

原对方栅格化还将矩形每边额外扩展半格对角线，旋转时四角存在不必要的多标记。现改为车身矩形与栅格方块的精确相交测试；仍标记所有与加padding车身相交的格子，不将真实车身缩小，也不取消碰撞检查。停车筛选继续保留保守的离散格子余量，实际派发前仍由原生规划器验证。

以下参数用途不同，继续独立保留：

- `inflation_radius`和`cost_scaling_factor`：软代价和离障偏好。
- `parked_peer_clearance_m`：两车净空下限；实际筛选至少覆盖自身padding、对方padding以及对方标记半格对角线的栅格余量。路径采样还保留插值运动余量。
- 激光过滤的`margin_m`：覆盖相对定位不确定性，作用于过滤雷达光束，不是扩大碰撞车身。

再次发生205/206时，C1会通过现有GetCostmap服务保留约1.2m见方的全局代价截图数据`occupied-costmap-robot1.json`或`occupied-costmap-robot2.json`，包含位姿、padding、静态空闲检查和原始代价值。每车最多每5仿真秒记录一次，不增加常驻订阅，不自动清除障碍。该记录能区分静态地图空闲但动态代价占据，尚不能单凭合并后的地图精确归因到每个图层。

这些调整需下一轮真实仿真验证C1；离线回放通过不等于实际协作已恢复。
