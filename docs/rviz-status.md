# RViz导航状态与图例

右侧面板优先显示：当前任务/到点策略、剩余路径距离、控制器与规划器配置、最近派发目标、恢复证据、控制器→平滑器→底盘指令→里程计速度，以及雷达/深度/局部代价图新鲜度。双机任务有状态输入时显示机器人2的任务阶段。最近导航警告附墙钟年龄，只作为诊断线索，不认定根因。

`正在跟踪路径`来自新鲜仲裁状态，不能用屏幕上仍保留的路径判断。`路径跟踪停滞`要求活动任务、跟踪状态及新鲜里程计连续5仿真秒低速；阈值是显示提示，不改变导航和恢复。`RPP控制计算受阻`来自当前RPP诊断的BLOCKED报告，不等于物理接触。

恢复区分动作执行、动作失败、位移证据和导航恢复；动作成功不能直接显示脱困成功。深度区分配置关闭、开启但无新数据、数据新鲜。已标记障碍不会因为点云断流自动清除。

图例默认展开，解释轨迹、目标、两种包络、雷达、深度和代价图。青色深度点包含清障用地面点，不全是障碍。橙色箭头始终表示最近派发目标，任务结束后可能仍保留。黄色RPP前视点不是全局目标。雷达改为固定红色，与图例一致。

数据频率表、同刻TF错误和SLAM锚点修正放在`数据时序与TF细节`折叠区。锚点修正不是定位误差。诊断按4Hz墙钟刷新，仿真暂停时仍报告时钟未推进；消息年龄和频率主要按仿真时间，另用墙钟检查断流。

只读实现：`scripts/ros/navigation_diagnostics.py`采集，`navigation_status.py`组织显示，`src/edgeai_navigation_rviz/src/navigation_panel.cpp`呈现。运行配置取自会话`nav2-runtime.yaml`，显示的控制器/规划器来自到点策略与该配置，不声称证明插件正在执行。显示警告同步进入`alignment.jsonl`，不发速度、目标或参数修改。
