--- Slide 2 ---
Challenge overview
02
Each team will control a group of approximately four wheeled mobile robots operating in an unknown indoor environment. During the mission, the robots may need to:
Explore an initially unknown environment
Detect, identify, and localize different targets
Share information between robots and edge node
Allocate tasks among robots
Form robot groups to complete specific rescue tasks
Adapt their behavior according to mission updates
Manage computation, communication, or energy consumption
Core theme: AI + Robotics + Edge Computing + Communication + Control

--- Slide 3 ---
System architecture - overview
03
1. Mobile robot team
Robots perform sensing, local computation, motion control, and exploration. 
Robots can communicate and share local information with each other.
2. Edge computing node
A single local computing server is available to each team. 
Teams decide which tasks are executed onboard and which are offloaded to the edge. 
Typical edge functions may include: multi-robot coordination; perception/object detection; map fusion; task allocation; LLM inference.
3. Human operator + LLM
The human operator provides natural-language mission updates. 
The LLM interprets the instructions and converts them into executable tasks.

--- Slide 4 ---
Competition environment
05
Illustrative arena
In-door, flat-floor environment of approximately 5m × 5m (final dimensions are TBD), containing rooms, walls, and static obstacles.
Rescue targets are represented by ArUco visual markers and divided into two types:  Normal Targets and Cooperative Targets.
Rescue zone is used for rescue-completion verification. Each ArUco marker corresponds to one or more predefined Rescue Zones.
A rescue is completed when the robot enters the corresponding Rescue Zone and remains there continuously for the required duration.

Task 1   Autonomous exploration, mapping, and detection
06
Teams may use up to two robots starting from a designated start area to autonomously explore an unknown environment and build a unified 2D occupancy grid map within limited time:
The robot system shall operate autonomously based on the current map and sensor information, performing path planning, obstacle avoidance, and motion execution toward the selected target;
Existing ROS 2 SLAM, navigation, and other open-source software packages are allowed.

Task 2A is also time-limited and ends when one of the following conditions occurs: (1) The competition time limit is reached; (2) All valid rescue targets have been successfully completed; (3) The referee terminates the run due to safety, equipment failure, or another necessary reason.
